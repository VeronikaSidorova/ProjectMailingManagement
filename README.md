# Проект сервис управления рассылками, администрирования и получения статистики

## Описание

Данный проект - это веб-приложение на Django, которое позволяет пользователям управлять рассылками сообщений для клиентов. Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, а также отправки сообщений по требованию.
